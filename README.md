# 온라인몰 건강기능식품 판매순위 크롤러

올리브영 · 다이소몰 · 카카오 선물하기의 건강기능식품 판매순위 TOP10을 매일
자동 수집하고, 월별 평균순위 TOP20을 집계합니다.

자세한 구조와 로직은 [설계서.md](./설계서.md), 진행 경위·의사결정 배경은
[기록.md](./기록.md)를 참고하세요. 올리브영 자동 수집이 막혔을 때는
[크롤러_실패시.md](./크롤러_실패시.md)를 따라 수동 보완합니다.

## 순위 산정 방식

월별취합의 "순위(월평균)"은 단순 평균순위가 아니라, **하루 점수(1위=5점 …
10위=0.5점)를 실제 수집일수로 나눈 값**으로 매깁니다. 그 달에 등장하지
못한 날은 0점으로 셈에 들어가기 때문에, 며칠만 반짝 상위권이었던 상품은
안 나온 날들이 점수를 깎아내려 매일 꾸준히 상위권을 지킨 상품을 앞지르지
못합니다.

> 예: A상품(등장 5일, 그 5일 모두 1위 → 평균순위 1.0)보다 B상품(등장
> 15일, 평균순위 5.33)이 최종 순위에서 더 위에 올 수 있습니다. 카드형
> 시트의 "평균순위"는 등장한 날만의 단순 평균이라 최종 순위와 다르게
> 보일 수 있는데, 이런 경우는 월별요약 시트의 "반짝 상위권 상품" 표에
> 자동으로 표시됩니다.

공식은 [설계서.md](./설계서.md) 9장 "월별 집계 로직", 개편 경위는
[기록.md](./기록.md) 2026-08-25 항목을 참고하세요.
